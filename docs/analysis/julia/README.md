# Julia Implementation Reference

This directory contains the original Julia implementation files used as reference for the Lean 4 verification project.

## Files

- **StepByStep.jl** — Step-by-step SAT machine execution (Julia version)
- **ReaderStepByStepJulia.jl** — Reader algorithm implementation (Julia version)
- **TseitinReaderJulia.jl** — Tseitin formula reader (Julia version)
- **VisualizeGPathJulia.jl** — Graph path visualization (Julia version)

## Purpose

These files document the original Julia algorithms that the Lean 4 implementation mirrors. They serve as reference implementations and comparison baselines for validation.
